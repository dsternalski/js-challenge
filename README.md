Title: Bitlight Coding Challenge
Author: Daniella Sternalski-Gobey

Running the code:
1) Bring the files down from the following GitHub location:https://github.com/dsternalski/js-challenge
2) Using cmd line, navigate to your empty folder where you will run the node, e.g. cd D:\BiglightChallenge\node
3) To run the node files, type the following into the cmd panel:
node index

NOTE: Make sure that the node is running first before you view the test and that your cache and cookies are cleared.

Structure: The project contains several files and folders:
- ConsoleTemplates: Contains my original challenge files.
- node: Contains the node projects.
-- node_modules: Contains node packages
-- public: Contains the css and js folders and files.
-- scss: Contains the challenge scss files.

Challenge 1:
I started this challenge by writing code for the console. You can see that code in the ConsoleTemplates/challenge_1.js. I started by creating a basic template that was to be used across both challenges. Once I got the majority of the challenge complete. I moved onto Challenge 2.

Challenge 2:
Using my base template from Challenge 1, I created the challenge_2.js file also in the ConsoleTemplates folder.

Both challenges:
My main approach for both of the challenges is the same in the sense that I started with the DOM manipulation, so getting the code added to the page. Once this was done, I then looked at the styling and lastly, I looked at the functionality, so with challenge 1 that was the hiding of the bar when scrolling and with challenge 2 that was the inserting before functionality.

I then took what I had done and placed them into the node part of the project. As this particular approach was new to me, I started by getting the basics of the node part up and running and ensuring that I could access the public files.

Once that was established, I then looked at Gulp and SCSS. I started with a basic file and once I was happy that I understood it, I removed the CSS out of the challenge js files, added in the relevant SCSS variables and complied the CSS files.
